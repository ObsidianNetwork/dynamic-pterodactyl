Single-route entry point `routes/api.php` groups all endpoints under `/api/dynamic-pterodactyl` with three distinct scopes: public availability/pricing routes protected by `web`, `auth`, and a `throttle:30,1` rate limiter; checkout reservation routes (`/reservation`) additionally gated by a custom `checkout` middleware and `throttle:10,1`; and admin routes under `/admin` further enforced by the `EnsureUserIsAdmin` middleware. Controllers in `Http/Controllers/Api/` are thin — they validate via FormRequest classes in `Http/Requests/`, delegate business logic to `Services\ReservationService` (and other service classes), and return uniform JSON responses with `success`/`data`/`message` keys. Authorization is handled per-action via Laravel's `$this->authorize()` policy calls on `ResourceReservation` models, while admin-only access is enforced centrally by the `EnsureUserIsAdmin` middleware that rejects requests when `request()->user()` or `user->role` is null. The layer depends outward only on services, models, and policies — no direct DB queries except simple token lookups in controllers.
