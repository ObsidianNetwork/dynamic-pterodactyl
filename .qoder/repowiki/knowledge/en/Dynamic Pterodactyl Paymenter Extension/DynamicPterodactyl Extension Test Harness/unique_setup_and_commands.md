`DB_DATABASE` must be `paymenter_test` or `:memory:` (or unset) — `bootstrap.php` aborts with exit code 2 on any other value to prevent accidental writes to production databases. Feature API tests must manually `require routes/api.php` in `setUp()` since routes are registered at runtime by the extension's boot method. The root `phpunit.xml` configures `MAIL_MAILER=array`, `SESSION_DRIVER=array`, `CACHE_STORE=array` with legacy `CACHE_DRIVER=file`, sync queue, and service-source warning restrictions.
